# 公式実例の収集

## 初回収集

2026-09-15に8種類・各2件、計16件を収集。辞書の定義と実例は別レコードにし、`partId` / `exampleIds` で関連付けています。パーツIDは既存のお気に入り・メモとの対応を維持しています。

## 記録する内容

| 領域 | フィールド |
| --- | --- |
| 辞書 | 日本語名・英語名・検索別名・役割・用途案・似た部品との違い・参考資料 |
| 実例 | デザインシステム・サンプル名・正規URL・独自要約・特徴・確認日 |
| 確認状態 | 資料確認・画像取得・確認した操作範囲・アクセシビリティ確認の有無 |
| 画像 | ローカルパス・取得元URL・取得日時・表示状態・対象セレクター・寸法・SHA-256 |
| 実装資料 | 存在を確認できたソースURL。未確認なら `null` |

`sourceTitle` は取得時の公式ページ名です。検索別名と宿泊などへの用途案は編集情報です。公式資料の原文そのものではありません。

## 追加手順

1. 公式ページを開き、目的の部品・サンプルが存在することを確認する。
2. 転送がある場合は正規URLと現行の名称を記録する。
3. 説明と特徴は必要な範囲で独自に要約する。ページの全文は収録しない。
4. 画像を取る場合は実際の公式UIの表示を取得し、対象と表示状態を記録する。自作デモや推測画像を公式実例の画像として登録しない。
5. 資料を読んだだけの挙動は「操作確認済み」にしない。画像がない実例は `image: null` にする。
6. `catalog.json` に追加し、`node scripts/build-catalog.mjs` で検証・生成する。

画像や参照実装の再利用ライセンスは、各公開元の条件に従います。この収集物からライセンスを推測して付与していないため、`reuseLicense` は未確認の `null` としています。取得画像は参照対象の識別に使用しています。
